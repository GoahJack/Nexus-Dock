## 自动更新，从这版开始

- 新增 Windows 安装版：启动后自动检查、后台下载新版本，在「设置 → 关于 → 软件更新」查看状态与下载进度。
- 下载完成后点击「重启更新」才安装，普通退出不会安装更新。可以关闭自动检查，继续手动检查与下载。
- 沿用现有的配置、窗口位置、灵动岛/图钉状态、应用列表、词库和学习进度。
- 保留便携版，并提供安装版迁移入口。

## 首次安装

请先退出旧版，再运行 **NexusDock-1.10.0-setup.exe**。旧便携版需要手动安装这一次；以后使用安装版，即可接收后续更高版本的更新。

v1.10.0 是自动更新的首个基线版本。安装后检查到 v1.10.0 时显示已是最新版；下次发布更高版本时会自动下载。

## 下载文件

| 文件 | 用途 |
| --- | --- |
| `NexusDock-1.10.0-setup.exe` | 推荐，Windows x64 安装版，支持后续自动更新 |
| `NexusDock-1.10.0-portable.exe` | Windows x64 便携版，手动更新 |
| `NexusDock-1.10.0-setup.exe.blockmap` | 自动更新差分下载文件，无需手动打开 |
| `latest.yml` | 自动更新版本与校验清单，无需手动打开 |
